# DEVEL_MASTER Test Bot

اختبار استراتيجية DEVEL_MASTER في قناة تيليجرام منفصلة.

## الإعداد السريع

1. أنشئ بوت جديد عبر @BotFather في تيليجرام
2. أنشئ قناة اختبار وأضف البوت كـ admin
3. انسخ .env.example إلى .env وعبّئ القيم
4. ادفع لـ Railway واضبط المتغيرات هناك

## المتغيرات المطلوبة على Railway
- TEST_BOT_TOKEN — توكن بوت الاختبار
- TEST_CHANNEL_ID — ID قناة الاختبار

## ما يفعله البوت
- يمسح 40 عملة كل 4 ساعات
- يُرسل إشارات DEVEL_MASTER للقناة
- يتتبع نتائج الإشارات (WIN/LOSS)
- يُرسل ملخصاً كل 24 ساعة
